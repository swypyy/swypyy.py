# Swypyy.py

A beginner-friendly static website and learning project focused on Python, web development, and personal experimentation.

🌐 Live demo: [swypyy.github.io/swypyy.py/](https://swypyy.github.io/swypyy.py/)

## Overview

This repository contains a small front-end project built to explore HTML, CSS, JavaScript, and lightweight web design. It acts as a personal sandbox for learning how to structure webpages, style content, and add simple interactive behavior.

## Features

- Clean landing page layout
- Responsive design
- Static website structure
- Educational project pages and references
- Lightweight front-end experience without heavy frameworks

## Project structure

- `index.html` – main page
- `assets/` – images, media, and supporting files
- `css/` – stylesheet files
- `js/` – JavaScript logic and interactions
- `learn-python/` – resources or content related to learning Python

## Run locally

Because this is a static site, you can preview it with a simple local server.

```bash
git clone https://github.com/swypyy/swypyy.py.git
cd swypyy.py
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
