Python Syntax and Indentation

Learn the basic rules of writing Python code. Understand statements, indentation, code blocks, and how to recognise common syntax mistakes.

1. Introduction to Python Syntax

Every programming language has rules that explain how its instructions must be written. These rules are called syntax.

Python syntax describes how to write instructions that Python can understand and execute.

For example, look at this simple Python instruction: 

print("Hello, Python!")
Output
Hello, Python!

This instruction tells Python to display the message Hello, Python!.

Remember: Syntax is the set of rules we follow when writing code. Just like a natural language has grammar, a programming language has syntax.

2. Understanding Python Statements

A statement is an instruction that Python can execute. A Python program is usually made up of several statements.

Consider this example:

print("Welcome")
print("I am learning Python")
print("This is my first module")
Output
Welcome
I am learning Python
This is my first module

Each print() instruction is a separate statement. Python executes these statements in order, from top to bottom.

Do Python statements need semicolons?

In Python, you normally write one statement on each line. A semicolon is not required at the end of a statement. 

name = "Sam"
age = 16

print(name)
print(age)

Beginner tip: Write one statement per line. It makes your code easier to read and understand.

3. Basic Rules of Python Syntax

Python has several basic rules that you should remember while writing programs.

Rule 1: Python is case-sensitive

Python treats uppercase and lowercase letters as different characters. 

name = "Alex"
Name = "Riya"

print(name)
print(Name)
Output
Alex
Riya

Here, name and Name are two different variable names.

Rule 2: Brackets must be matched

When you open parentheses, square brackets, or curly brackets, you must close them properly. 

print("Hello")

The opening and closing parentheses match. Forgetting a closing bracket can cause a syntax error.

Rule 3: Text needs quotation marks

Text values are written inside single or double quotation marks. 

print("Good morning")
print('Welcome to Python')

Both examples are valid. The opening and closing quotation marks should match.

Rule 4: Use clear and consistent names

When creating names for variables and functions, choose names that describe their purpose. You will learn more about variables in the next lesson.

4. What Is Indentation?

Indentation means adding spaces at the beginning of a line of code.

Python uses indentation to identify which statements belong together inside a code block. This is an important part of Python syntax.

Look at this example:

if 10 > 5:
    print("10 is greater than 5")

Notice the spaces before print(). The indented statement belongs to the if block.

Output
10 is greater than 5

Important: Python commonly uses four spaces for each indentation level. Using four spaces is the recommended style.

Correct indentation

if 5 > 2:
    print("The condition is true")
    print("This line is also inside the if block")

print("This line is outside the if block")

Incorrect indentation

if 5 > 2:
print("The condition is true")

The second example is incorrect because the statement after the if line is not indented.

5. Understanding Code Blocks

A code block is a group of statements that belong together. In Python, indentation identifies the statements inside a block.

A colon (:) is commonly used to begin a block after statements such as if, for, while, and function definitions.

Here is a simple example:

if 8 > 3:
    print("First statement")
    print("Second statement")

print("Outside the block")
Output
First statement
Second statement
Outside the block

The first two print statements are indented at the same level. They belong to the if block.

The last statement has no indentation, so it is outside that block.

if 8 > 3:
↓
Indented statement 1
↓
Indented statement 2
↓
Statement outside the block

6. Common Syntax and Indentation Errors

Beginners often make small mistakes while writing code. Python reports these problems so that you can correct them.

Error 1: Missing closing parenthesis

print("Hello"

The closing parenthesis is missing. Python cannot correctly understand the incomplete instruction.

Error 2: Missing quotation mark

print("Welcome to Python)

The text starts with a double quotation mark, but there is no matching closing quotation mark.

Error 3: Missing colon

if 10 > 5
    print("True")

The colon is missing after the condition. A colon is required here to introduce the if block.

Error 4: Incorrect indentation

if 10 > 5:
print("True")

The statement inside the if block must be indented.

Error 5: Inconsistent indentation

Mixing tabs and spaces carelessly can cause indentation problems. Use four spaces for each indentation level and keep the style consistent.

Remember: A SyntaxError means Python found code that does not follow its grammar rules. An IndentationError is a specific kind of syntax error related to indentation.

7. Practical Coding Exercises

Now it is time to practise. Try these exercises in your Python editor or an online Python environment.

Exercise 1: Display three messages

Write a program that displays your name, your school subject, and a message saying that you are learning Python.

Example solution:

print("My name is Alex")
print("I study Science")
print("I am learning Python")

Exercise 2: Identify the indentation

Study this program and identify which statements belong to the if block. 

if 7 > 4:
    print("Line A")
    print("Line B")

print("Line C")

Answer: Line A and Line B belong to the if block. Line C is outside it.

Exercise 3: Fix the code

The following code contains an indentation mistake. Correct it and run the program. 

if 20 > 10:
print("20 is greater than 10")

Correct version:

if 20 > 10:
    print("20 is greater than 10")

Exercise 4: Predict the output

Before running this program, try to predict what it will display. 

print("Start")
print("Learning Python")
print("End")

Check your prediction by running the code. Python executes these statements in order.

Practice habit: Write the code, predict the output, run it, and compare your prediction with the actual result.
