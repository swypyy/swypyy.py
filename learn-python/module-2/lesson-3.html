Data Types

Learn how Python classifies different kinds of information. Understand integers, floating-point numbers, strings, booleans and other important built-in data types.

1. What Are Data Types?

Every value in Python has a data type. A data type tells Python what kind of value it is working with and what operations can be performed on that value.

For example, a person's age is usually represented as a whole number, their name as text, and their height as a decimal number. These values have different data types.

Example
name = "Anu"
age = 16
height = 1.65
is_student = True

Python provides several built-in data types.

int

Whole numbers, such as 10 and -5.

float

Numbers with decimal points, such as 3.14.

str

Text, such as "Hello".

bool

Logical values: True or False.

list

An ordered collection of values.

dict

A collection of key-value pairs.

tuple

An ordered, immutable collection.

set

A collection of unique values.

This lesson focuses mainly on the basic types you will use frequently. Collections such as lists, tuples, sets and dictionaries will be explored in detail later.

2. Integer Data Type (int)

An integer is a whole number without a decimal point. Integers can be positive, negative or zero.

Examples
age = 16
temperature = -5
students = 40
balance = 0

print(age)
print(temperature)

Output:

16
-5

Python uses the int type for these values. Integers are useful for counting objects, storing ages, and representing quantities that do not require fractions.

Integer arithmetic

You can perform mathematical operations using integers. 

a = 20
b = 6

print(a + b)
print(a - b)
print(a * b)

Output:

26
14
120

Remember: A value such as 25 is an integer, while 25.0 is a floating-point number.

3. Floating-Point Data Type (float)

A float represents a number that contains a decimal point. It is useful for measurements, averages, prices and other values that can contain fractions.

Examples
height = 1.72
price = 99.50
temperature = -2.5
average = 87.25

print(height)
print(price)

Output:

1.72
99.5

Notice that Python displays 99.50 as 99.5. Both represent the same numerical value.

Float calculations

length = 5.5
width = 3.0

area = length * width

print(area)

Output:

16.5

Floating-point numbers can sometimes produce tiny rounding differences because many decimal fractions cannot be represented exactly in binary. This is normal computer behaviour.

4. String Data Type (str)

A string is a sequence of characters used to represent text. Strings are written inside single quotes, double quotes or triple quotes.

Examples
name = "Ravi"
city = 'Kannur'
message = """Welcome to Python!"""

print(name)
print(city)
print(message)

Output:

Ravi
Kannur
Welcome to Python!

Strings can contain different characters

word = "Python"
number_text = "123"
greeting = "Hello, World!"

print(word)
print(number_text)
print(greeting)

Even though number_text contains digits, it is still a string because it is surrounded by quotes.

Joining strings

You can join strings using the + operator. This operation is called concatenation. 

first_name = "Asha"
last_name = "Kumar"

full_name = first_name + " " + last_name

print(full_name)

Output:

Asha Kumar

5. Boolean Data Type (bool)

A boolean represents one of two logical values: True or False. Boolean values are commonly used in conditions and decision-making.

Example
is_raining = True
is_sunny = False

print(is_raining)
print(is_sunny)

Output:

True
False

Notice that True and False begin with capital letters in Python. Writing true or false in lowercase does not create boolean values.

Boolean values from comparisons

Comparison operations produce boolean results. 

print(10 > 5)
print(8 == 3)
print(7 != 2)

Output:

True
False
True

These results can later be used in if statements and loops.

6. Checking Data Types with type()

Python provides the built-in type() function to identify the type of a value or variable.

Example
age = 16
height = 1.72
name = "Meera"
is_student = True

print(type(age))
print(type(height))
print(type(name))
print(type(is_student))

Output:

<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>

The output tells you the type of each value:

  • int means integer.
  • float means floating-point number.
  • str means string.
  • bool means boolean.

Useful habit: When you are unsure what type a variable contains, use type() to investigate it.

7. Understanding None and NoneType

Python has a special value called None. It represents the absence of a value or a value that has not been provided.

Example
result = None

print(result)
print(type(result))

Output:

None
<class 'NoneType'>

The type of None is called NoneType.

Why is None useful?

Sometimes a program needs a variable before its final value is available. You can use None as a temporary placeholder. 

selected_subject = None

selected_subject = "Physics"

print(selected_subject)

Output:

Physics

None is not the same as zero, False or an empty string (""). They are different values with different meanings.

8. Mutable and Immutable Values

Python objects can be described as mutable or immutable.

  • Mutable: An object can be changed after it is created.
  • Immutable: An object cannot be changed after it is created.

Integers, floats, strings, booleans and tuples are examples of immutable types. Lists, dictionaries and sets are examples of mutable types.

Example: Strings are immutable

word = "Python"

word = "Java"

print(word)

Output:

Java

This does not change the original string object. Instead, the variable is assigned to a different string.

Example: Lists are mutable

numbers = [10, 20, 30]

numbers[0] = 99

print(numbers)

Output:

[99, 20, 30]

The list itself has been modified. You will study lists and other collections in more detail in Module 5.

9. Common Data Type Mistakes

Mistake 1: Treating a number string as a number

number = "10"

print(number + 5)

This causes a TypeError because Python cannot directly add a string and an integer.

Mistake 2: Forgetting quotation marks

name = Ravi

Python treats Ravi as a variable name rather than text. If that variable has not been defined, a NameError occurs.

Correct version:

name = "Ravi"

Mistake 3: Incorrect boolean spelling

is_active = true

Correct version:

is_active = True

Mistake 4: Confusing 10 and "10"

number = 10
text = "10"

print(type(number))
print(type(text))

The first value is an integer. The second value is a string. They may look similar, but Python treats them differently.
