Type Conversion

Learn how to convert values between different Python data types and understand when type conversion is useful.

1. What Is Type Conversion?

Type conversion is the process of changing a value from one data type into another.

Python supports different data types such as integers, floats, strings, and booleans. Sometimes, a program needs to convert one type into another to perform an operation.

For example:

number = "25"

print(type(number))

converted_number = int(number)

print(type(converted_number))
OUTPUT
<class 'str'>
<class 'int'>

Initially, number contains the string "25". The int() function converts it into an integer.

Remember: The value "25" is text, while 25 is an integer. They may look similar, but Python treats them differently.

2. Types of Type Conversion

Python type conversion is commonly divided into two types:

  • Implicit Type Conversion: Python automatically converts a value from one compatible type to another in certain operations.
  • Explicit Type Conversion: The programmer manually converts a value using functions such as int() or str().

Implicit Type Conversion

Implicit conversion happens automatically. Python performs it when an operation involves compatible numeric types. 

number = 10
decimal = 2.5

result = number + decimal

print(result)
print(type(result))
OUTPUT
12.5
<class 'float'>

Python converts the integer to a float for the calculation, so the result is a float.

Explicit Type Conversion

Explicit conversion happens when the programmer deliberately changes a value's type. 

number = "100"

converted = int(number)

print(converted)
print(type(converted))
OUTPUT
100
<class 'int'>

Here, the programmer uses int() to convert a string into an integer.

3. Converting Values to Integers

The int() function converts compatible values into integers.

Converting a Float to an Integer

price = 49.99

whole_number = int(price)

print(whole_number)
OUTPUT
49

Notice that int() removes the decimal part. It does not round the number to the nearest integer.

Converting a String to an Integer

age = "16"

age_number = int(age)

print(age_number + 1)
OUTPUT
17

The string contains valid integer digits, so Python can convert it successfully.

Important: A string such as "hello" cannot be converted into an integer using int(). Python raises a ValueError.

4. Converting Values to Floats

The float() function converts compatible values into floating-point numbers.

Converting an Integer to a Float

number = 25

decimal_number = float(number)

print(decimal_number)
print(type(decimal_number))
OUTPUT
25.0
<class 'float'>

Converting a String to a Float

price = "99.50"

converted_price = float(price)

print(converted_price)
print(type(converted_price))
OUTPUT
99.5
<class 'float'>

Python can convert a numeric string containing a decimal point into a float.

5. Converting Values to Strings

The str() function converts a value into its string representation.

Converting an Integer to a String

age = 16

age_text = str(age)

print(age_text)
print(type(age_text))
OUTPUT
16
<class 'str'>

Combining Text and Numbers

You can use str() to convert a number before joining it with another string. 

age = 16

message = "I am " + str(age) + " years old."

print(message)
OUTPUT
I am 16 years old.
Tip: You can also use an f-string to display numbers inside text without manually calling str().

6. Converting Values to Booleans

The bool() function converts a value into either True or False.

Python considers certain values to be false when converted to a boolean.

Values That Become False

  • 0 and 0.0
  • "", an empty string
  • [], an empty list
  • {}, an empty dictionary
  • None
  • False
print(bool(0))
print(bool(""))
print(bool([]))
print(bool(None))
OUTPUT
False
False
False
False

Values That Become True

Most other values become True, including non-zero numbers and non-empty strings. 

print(bool(10))
print(bool(-5))
print(bool("Python"))
print(bool([1, 2, 3]))
OUTPUT
True
True
True
True
Remember: The string "False" is not the same as the boolean value False. Since it is a non-empty string, bool("False") returns True.

7. Type Conversion with User Input

The input() function always returns the entered value as a string.

If you want to perform mathematical calculations with user input, you often need to convert that input first.

Example: Adding Two Numbers

num1 = input("Enter first number: ")
num2 = input("Enter second number: ")

result = num1 + num2

print(result)

If the user enters 10 and 20, the output is:

OUTPUT
Enter first number: 10
Enter second number: 20
1020

This happens because both inputs are strings. The + operator joins them instead of adding them mathematically.

Correct Approach

num1 = int(input("Enter first number: "))
num2 = int(input("Enter second number: "))

result = num1 + num2

print("Total:", result)
OUTPUT
Enter first number: 10
Enter second number: 20
Total: 30

Now both inputs are converted into integers before the addition takes place.

8. Converting Between Other Types

Python provides other conversion functions too. Here are a few useful examples.

Converting a String to a List

word = "Python"

letters = list(word)

print(letters)
OUTPUT
['P', 'y', 't', 'h', 'o', 'n']

Converting a List to a Tuple

numbers = [10, 20, 30]

result = tuple(numbers)

print(result)
OUTPUT
(10, 20, 30)

Converting a List to a Set

numbers = [1, 2, 2, 3, 3, 4]

result = set(numbers)

print(sorted(result))
OUTPUT
[1, 2, 3, 4]

A set stores unique values, so repeated elements are removed. The example uses sorted() to display the values in a predictable order.

9. Common Type Conversion Errors

ValueError

A ValueError occurs when a conversion function receives a value in an unsuitable format. 

number = int("hello")

Python cannot convert the word "hello" into an integer.

TypeError

A TypeError can occur when an operation uses incompatible data types. 

number = 10
text = "5"

result = number + text

Python does not automatically combine an integer and a string using the addition operator.

Safe Conversion with try and except

You can handle invalid input using exception handling. You will study this topic in more detail later. 

value = input("Enter a number: ")

try:
    number = int(value)
    print("Number:", number)
except ValueError:
    print("Please enter a valid whole number.")
EXAMPLE OUTPUT
Enter a number: hello
Please enter a valid whole number.

12. Lesson Summary

In this lesson, you learned how to convert values between different Python data types.

  • Type conversion changes a value from one data type to another.
  • Implicit conversion happens automatically in compatible operations.
  • Explicit conversion is performed using conversion functions.
  • int() converts compatible values into integers.
  • float() converts compatible values into floats.
  • str() converts values into strings.
  • bool() converts values into booleans.
  • input() returns a string.
  • Invalid conversions can raise errors such as ValueError.
