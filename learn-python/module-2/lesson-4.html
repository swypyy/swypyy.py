Numbers and Mathematical Operations

Learn how Python works with numbers and performs mathematical calculations using arithmetic operators.

1. Introduction to Numbers in Python

Numbers are one of the most commonly used data types in programming. Python allows us to store numbers, perform calculations, compare values, and solve mathematical problems.

For example, Python can calculate the total price of products, find the average of marks, calculate distances, and much more.

Unlike some programming languages, Python makes mathematical operations simple and readable. 

print(10 + 5)
print(20 - 8)
print(6 * 4)
print(20 / 5)
OUTPUT
15
12
24
4.0

Python can perform these calculations directly without requiring us to create variables first.

Remember: Python follows standard mathematical rules when performing calculations. The operators you use determine what operation takes place.

2. Types of Numbers in Python

Python mainly provides three built-in numeric types:

  • int: Whole numbers without decimal points.
  • float: Numbers containing decimal points.
  • complex: Numbers containing a real and an imaginary part.

Integer (int)

Integers are whole numbers. They can be positive, negative, or zero. 

age = 16
temperature = -5
score = 0

print(type(age))
print(type(temperature))
OUTPUT
<class 'int'>
<class 'int'>

Float (float)

Floats are numbers that contain a decimal point. 

price = 99.50
height = 5.8
pi = 3.14159

print(type(price))
print(type(height))
OUTPUT
<class 'float'>
<class 'float'>

Complex Numbers (complex)

Complex numbers contain two parts: a real part and an imaginary part. Python uses j to represent the imaginary unit. 

number = 3 + 4j

print(number)
print(type(number))
OUTPUT
(3+4j)
<class 'complex'>

Complex numbers are useful in advanced mathematics, engineering, and scientific computing.

3. Arithmetic Operators in Python

Arithmetic operators are symbols used to perform mathematical calculations.

Python supports these main arithmetic operators:

a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(a ** b)
OUTPUT
13
7
30
3.3333333333333335
3
1
1000

Addition (+)

The addition operator adds two numbers. 

result = 15 + 5
print(result)
OUTPUT
20

Subtraction (-)

The subtraction operator finds the difference between two numbers. 

result = 25 - 10
print(result)
OUTPUT
15

Multiplication (*)

The multiplication operator multiplies two numbers. 

result = 6 * 7
print(result)
OUTPUT
42

Division (/)

The division operator divides one number by another. It returns a float, even when the result is a whole number. 

result = 20 / 4
print(result)
OUTPUT
5.0

Floor Division (//)

Floor division divides two numbers and rounds the result down to the nearest whole integer when both operands are integers. 

result = 17 // 5
print(result)
OUTPUT
3
Important: Floor division rounds down, not simply towards zero. For example, -17 // 5 produces -4.

4. Modulus and Exponentiation

Modulus (%)

The modulus operator returns the remainder after division. 

result = 17 % 5
print(result)
OUTPUT
2

This is useful when checking whether a number is even or odd. 

number = 12

if number % 2 == 0:
    print("Even number")
else:
    print("Odd number")
OUTPUT
Even number

Exponentiation (**)

The exponentiation operator raises a number to a power. 

result = 2 ** 4
print(result)
OUTPUT
16

Here, 2 ** 4 means 2 multiplied by itself four times: 2 × 2 × 2 × 2.

5. Order of Operations (Operator Precedence)

When a mathematical expression contains multiple operators, Python follows a specific order to decide which operation should be performed first.

This is called operator precedence. It follows rules similar to the mathematical BODMAS/PEMDAS order. 

result = 10 + 5 * 2
print(result)
OUTPUT
20

Multiplication happens before addition. Therefore, Python calculates 5 × 2 first, then adds 10.

Basic order of precedence

  1. Parentheses: ()
  2. Exponentiation: **
  3. Multiplication, division, floor division, and modulus.
  4. Addition and subtraction.
print((10 + 5) * 2)
print(2 ** 3 + 4)
print(20 / 5 + 3)
OUTPUT
30
12
7.0
Tip: Use parentheses when you want to make the order of a calculation clear. They also make complicated expressions easier for humans to understand.

6. Assignment Operators

Assignment operators are used to assign values to variables and update their existing values.

The basic assignment operator is =. Python also provides shorthand operators. 

number = 10

number += 5
print(number)

number -= 3
print(number)

number *= 2
print(number)

number /= 4
print(number)
OUTPUT
15
12
24
6.0

Here are some common assignment operators:

  • += Adds a value and assigns the result.
  • -= Subtracts a value and assigns the result.
  • *= Multiplies and assigns the result.
  • /= Divides and assigns the result.
  • //= Performs floor division and assigns the result.
  • %= Finds the remainder and assigns the result.
  • **= Raises to a power and assigns the result.

7. Working with Numbers and Variables

You can store numbers in variables and use those variables in mathematical expressions.

Example: Calculating the Area of a Rectangle

The area of a rectangle is calculated by multiplying its length by its width. 

length = 12
width = 5

area = length * width

print("Area:", area)
OUTPUT
Area: 60

Example: Calculating an Average

You can calculate the average of three numbers by adding them and dividing the total by 3. 

mark1 = 80
mark2 = 90
mark3 = 70

average = (mark1 + mark2 + mark3) / 3

print("Average:", average)
OUTPUT
Average: 80.0

8. Common Mistakes When Working with Numbers

Mistake 1: Dividing by Zero

Division by zero is not allowed in Python. It raises a ZeroDivisionError. 

result = 10 / 0

Mistake 2: Mixing Strings and Numbers

You cannot directly add a string and an integer using the addition operator. 

age = 16
print("Age: " + age)

Convert the number to a string or use an f-string instead. 

age = 16
print("Age: " + str(age))

# Another method
print(f"Age: {age}")
OUTPUT
Age: 16
Age: 16

Mistake 3: Confusing / and //

print(10 / 3)
print(10 // 3)
OUTPUT
3.3333333333333335
3
