Taking User Input

Learn how Python receives information from users using input(), stores entered values and uses them in programs.

1. What Is User Input?

Until now, most of our Python programs have used values that were already written in the code.

But real programs often need information from the person using them. For example, a program might ask for a name, age, favourite subject or a number.

User input is information provided by someone while a program is running.

Example: A Greeting Program

name = input("Enter your name: ")

print("Hello,", name)
SAMPLE INTERACTION
Enter your name: Anu
Hello, Anu

The program asks the user for a name, stores the entered text in the variable name, and then displays a greeting.

Remember: User input makes programs interactive. Instead of using only fixed values, a program can respond to information entered while it runs.

2. Understanding the input() Function

Python provides a built-in function called input() to receive information from users.

The basic syntax is: 

variable = input("Message shown to the user: ")

Let's understand each part:

  • input() is the function that waits for user input.
  • The message inside the quotation marks is called the prompt.
  • The variable stores the value entered by the user.

A Simple Example

city = input("Which city are you from? ")

print("You are from", city)
SAMPLE INTERACTION
Which city are you from? Kannur
You are from Kannur

The program pauses at input() until the user enters something and presses Enter.

The entered value is then returned by the function and assigned to the variable city.

3. Storing User Input in Variables

You can store input in variables just like you store ordinary values.

Example: Asking for a Favourite Subject

subject = input("Enter your favourite subject: ")

print("Your favourite subject is", subject)
SAMPLE INTERACTION
Enter your favourite subject: Physics
Your favourite subject is Physics

The variable subject stores whatever text the user enters.

Using Multiple Inputs

A program can ask several questions and store each answer in a different variable. 

name = input("Enter your name: ")
city = input("Enter your city: ")
hobby = input("Enter your hobby: ")

print("Name:", name)
print("City:", city)
print("Hobby:", hobby)
SAMPLE INTERACTION
Enter your name: Rahul
Enter your city: Kozhikode
Enter your hobby: Reading

Name: Rahul
City: Kozhikode
Hobby: Reading
Tip: Give each input its own meaningful variable name. This makes your code easier to understand and maintain.

4. Important: input() Always Returns a String

One of the most important rules about input() is that it returns the entered value as a string.

This is true even when the user enters digits. Python does not automatically treat the input as an integer or a float. 

age = input("Enter your age: ")

print(type(age))
SAMPLE INTERACTION
Enter your age: 17
<class 'str'>

Although the user entered 17, Python stored it as the string "17".

Why Does This Matter?

Consider this program: 

first = input("Enter first number: ")
second = input("Enter second number: ")

print(first + second)
SAMPLE INTERACTION
Enter first number: 10
Enter second number: 20
1020

The result is 1020, not 30, because both values are strings. The + operator joins the text together.

Key rule: If you want to perform mathematical calculations with numeric input, convert the entered value into an appropriate numeric type first.

5. Taking Integer Input

Use int() when you want to convert user input into an integer. 

age = int(input("Enter your age: "))

print("Next year, your age will be", age + 1)
SAMPLE INTERACTION
Enter your age: 17
Next year, your age will be 18

Notice the order of operations:

  1. input() receives the entered text.
  2. int() converts that text into an integer.
  3. The converted integer is stored in age.
  4. Python adds 1 to the value.

Another Example: Adding Two Integers

number1 = int(input("Enter first number: "))
number2 = int(input("Enter second number: "))

total = number1 + number2

print("Total:", total)
SAMPLE INTERACTION
Enter first number: 25
Enter second number: 15
Total: 40

6. Taking Decimal Input

When users need to enter decimal numbers, use float() instead of int(). 

price = float(input("Enter the price: "))

print("Price:", price)
SAMPLE INTERACTION
Enter the price: 49.50
Price: 49.5

Example: Calculating an Average

mark1 = float(input("Enter first mark: "))
mark2 = float(input("Enter second mark: "))

average = (mark1 + mark2) / 2

print("Average:", average)
SAMPLE INTERACTION
Enter first mark: 85
Enter second mark: 90
Average: 87.5

Using float() allows the program to accept both whole numbers and decimal values.

Remember: int() is for integer conversion. float() is for decimal-capable numeric conversion.

7. Taking Different Types of Input

You can combine different input types in the same program.

Example: A Simple Student Profile

name = input("Enter your name: ")
age = int(input("Enter your age: "))
height = float(input("Enter your height in metres: "))

print("Student Profile")
print("Name:", name)
print("Age:", age)
print("Height:", height)
SAMPLE INTERACTION
Enter your name: Anjali
Enter your age: 17
Enter your height in metres: 1.65

Student Profile
Name: Anjali
Age: 17
Height: 1.65

This program uses a string for the name, an integer for the age and a float for the height.

8. Using Input with Conditions

User input becomes more useful when combined with conditional statements.

A program can receive a value and make a decision based on that value.

Example: Checking a Number

number = int(input("Enter a number: "))

if number > 0:
    print("The number is positive")
elif number < 0:
    print("The number is negative")
else:
    print("The number is zero")
SAMPLE INTERACTION
Enter a number: 8
The number is positive

The program checks the entered number and displays a message based on its value.

Example: Simple Pass or Review Message

mark = float(input("Enter your mark: "))

if mark >= 50:
    print("You passed")
else:
    print("Keep practising")
SAMPLE INTERACTION
Enter your mark: 75
You passed

9. Common Input Errors

Entering Text Where an Integer Is Expected

Consider this program: 

age = int(input("Enter your age: "))

If the user enters a word instead of a valid integer, Python raises a ValueError. 

Enter your age: seventeen

ValueError: invalid literal for int()

This happens because Python cannot convert the word "seventeen" into an integer using int().

Using the Wrong Conversion Function

If a program expects decimal input, using int() may reject values such as 12.5. 

price = int(input("Enter price: "))

For decimal values, use float(): 

price = float(input("Enter price: "))

Handling Invalid Input

You can use try and except to handle invalid numeric input without immediately stopping the program. 

try:
    age = int(input("Enter your age: "))
    print("Your age is", age)

except ValueError:
    print("Please enter a valid whole number.")
SAMPLE INTERACTION
Enter your age: hello
Please enter a valid whole number.
Good practice: When converting user input, consider what happens if the user enters something unexpected.

12. Lesson Summary

In this lesson, you learned how Python receives information from users.

  • input() receives information while a program runs.
  • The message inside input() is called a prompt.
  • The entered value is stored in a variable.
  • input() always returns a string.
  • int() converts suitable input into an integer.
  • float() converts suitable input into a float.
  • Input can be combined with conditions and calculations.
  • try and except can handle invalid input.
