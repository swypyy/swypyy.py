Displaying Output

Learn how to display messages, values, and formatted information using Python's print() function.

1. Introduction to Displaying Output

A Python program often needs to show information to the person using it. This information is called output. Output can be a simple message, a calculation result, or a collection of values.

Python provides a built-in function called print() to display output in the console or terminal. You have already used it in your first Python program. 

print("Welcome to Python!")
print(25)
print(10 + 5)
OUTPUT
Welcome to Python!
25
15

The first statement displays text, the second displays a number, and the third displays the result of a calculation.

2. Understanding the print() Function

The print() function sends the values you provide to the program's standard output, usually the terminal.

The basic structure is: 

print(value)

The value inside the parentheses is what Python displays. It can be text, a number, a variable, or an expression.

Displaying different values

print("Hello")
print(100)
print(4.75)
print(True)
OUTPUT
Hello
100
4.75
True

Remember: Text must be placed inside quotation marks. Numbers and Boolean values can be written directly without quotation marks.

3. Displaying Variables

You can pass a variable directly to print(). Python displays the value stored in that variable. 

name = "Anu"
age = 16
score = 92.5

print(name)
print(age)
print(score)
OUTPUT
Anu
16
92.5

You can also display multiple variables in a single print() statement. By default, Python separates the values with spaces. 

name = "Anu"
age = 16

print(name, age)
OUTPUT
Anu 16

4. Displaying Multiple Values

The print() function accepts multiple values, separated by commas. Python displays them in order. 

print("Name:", "Ravi")
print("Age:", 17)
print("Marks:", 85, 90, 95)
OUTPUT
Name: Ravi
Age: 17
Marks: 85 90 95

This is useful when you want to combine labels and values without manually converting every value into text.

5. Using the sep Parameter

By default, print() separates multiple values with a single space. You can change this using the sep parameter. 

print("Python", "is", "fun", sep="-")
print(10, 20, 30, sep=" | ")
print("2026", "11", "13", sep="/")
OUTPUT
Python-is-fun
10 | 20 | 30
2026/11/13

The separator can be any string, including a comma, dash, symbol, or even an empty string.

Important: sep only controls the text placed between multiple values in one print() call.

6. Understanding the end Parameter

By default, every print() call ends with a newline. This means the next output starts on a new line. 

print("Hello")
print("World")
OUTPUT
Hello
World

You can change this behaviour using the end parameter.

Keeping output on the same line

print("Hello", end=" ")
print("World")
OUTPUT
Hello World

Using a custom ending

print("Loading", end="...")
print("Complete")
OUTPUT
Loading...Complete

The end parameter controls what Python adds after the values have been printed.

7. Using Escape Characters

Escape characters let you include special formatting inside a string. They begin with a backslash (\).

Common escape characters

  • \n - starts a new line.
  • \t - inserts a horizontal tab.
  • \\ - displays a backslash.
  • \" - displays a double quotation mark.
  • \' - displays a single quotation mark.

New line example

print("Python\nProgramming")
OUTPUT
Python
Programming

Tab example

print("Name\tAge")
print("Anu\t16")
OUTPUT
Name    Age
Anu     16

A tab usually creates a wider gap than a normal space. The exact alignment can depend on the terminal.

8. Formatting Output with f-Strings

Sometimes you need to display text together with variable values. Python's f-strings make this easy.

Put the letter f before the opening quotation mark, then place variable names or expressions inside curly braces {}. 

name = "Meera"
age = 16

print(f"My name is {name}.")
print(f"I am {age} years old.")
OUTPUT
My name is Meera.
I am 16 years old.

Using expressions inside f-strings

a = 10
b = 5

print(f"Total: {a + b}")
print(f"Product: {a * b}")
OUTPUT
Total: 15
Product: 50

Formatting decimal numbers

You can control how many decimal places are displayed. For example, {price:.2f} displays a number with two digits after the decimal point. 

price = 49.9876

print(f"Price: {price:.2f}")
OUTPUT
Price: 49.99

9. Using the format() Method

Another way to insert values into a string is the format() method. Place curly-brace placeholders in the string and provide the values using .format(). 

name = "Arun"
age = 17

message = "My name is {} and I am {} years old.".format(name, age)

print(message)
OUTPUT
My name is Arun and I am 17 years old.

You can also use numbered placeholders to choose the order of values. 

print("{1} is learning {0}".format("Python", "Anu"))
OUTPUT
Anu is learning Python

Tip: f-strings are usually the clearest choice for modern Python code when you are inserting variables into text.

10. Combining Strings and Values

You can join strings using the + operator. This is called string concatenation. 

first_name = "Anu"
last_name = "Krishnan"

full_name = first_name + " " + last_name

print(full_name)
OUTPUT
Anu Krishnan

Be careful when combining strings and numbers with +. Python does not automatically join a string and an integer. 

age = 16

# This causes a TypeError:
# print("Age: " + age)

# Convert the number to a string:
print("Age: " + str(age))

# Or use an f-string:
print(f"Age: {age}")
OUTPUT
Age: 16
Age: 16

11. Common Output Mistakes

Mistake 1: Forgetting quotation marks

# Incorrect
print(Hello)

# Correct
print("Hello")

Without quotation marks, Python treats Hello as a variable name.

Mistake 2: Mixing strings and numbers

# Incorrect
age = 16
# print("Age: " + age)

# Correct
print(f"Age: {age}")

Mistake 3: Incorrectly placing commas

# Displays two values separated by a space
print("Total:", 50)

# Displays one combined string
print("Total: " + str(50))

Mistake 4: Confusing sep and end

  • sep controls the space between values.
  • end controls what comes after the output.

14. Lesson Summary

In this lesson, you learned how to display information using Python.

  • print() displays output.
  • You can display text, numbers, variables, and expressions.
  • sep changes the separator between values.
  • end changes what appears after printed output.
  • \n creates a new line and \t inserts a tab.
  • f-strings insert variables and expressions into text.
  • format() is another way to format strings.
  • str() converts values to strings when needed.

Key takeaway: Good output makes a program easier to understand and use. Practise using print() with variables, separators, and f-strings to display information clearly.
