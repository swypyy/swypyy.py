Variables

Learn how Python stores and works with information using variables. You'll create variables, update their values and understand how Python handles different data types.

1. What Are Variables?

A variable is a name that refers to a value in a Python program. Variables allow us to store information and use it whenever we need it.

Imagine you are building a student record program. You may need to work with a student's name, age and marks. Instead of repeatedly writing each value, you can store them using variables.

Example
student_name = "Anu"
age = 16
marks = 92

print(student_name)
print(age)
print(marks)

Output:

Anu
16
92

Here, student_name, age and marks are variable names. They refer to the values stored in the program.

Remember: A variable is a name that refers to a value. You can use that name later to access or change the value.

2. Creating and Assigning Variables

In Python, you create a variable by choosing a name and assigning a value to it with the equals sign (=).

Syntax
variable_name = value

For example:

city = "Kannur"
temperature = 30
is_sunny = True

The equals sign is called the assignment operator. It assigns the value on the right to the variable name on the left.

Different kinds of values

name = "Ravi"       # A string
age = 17            # An integer
height = 1.72       # A float
is_student = True   # A boolean

Python identifies the type of value automatically. You do not need to declare a variable's type before assigning a value.

3. Rules for Naming Variables

You can choose meaningful names for variables, but Python follows certain naming rules.

Important naming rules

  • A variable name must begin with a letter or an underscore (_).
  • It can contain letters, numbers and underscores.
  • It cannot begin with a number.
  • Spaces are not allowed in variable names.
  • Python keywords cannot be used as variable names.
  • Variable names are case-sensitive.

Valid variable names

name = "Meera"
student_age = 16
marks2 = 85
_total = 100

Invalid variable names

2marks = 85       # Cannot begin with a number
student age = 16  # Spaces are not allowed
class = "A"       # 'class' is a Python keyword

Case sensitivity

Python treats uppercase and lowercase letters as different characters. Therefore, age, Age and AGE are three different variable names. 

age = 16
Age = 18

print(age)
print(Age)

Output:

16
18

Good practice: Use descriptive names such as student_name instead of unclear names such as x. Python programmers commonly use snake_case, where words are separated by underscores.

4. Updating Variable Values

Variables are not limited to their original values. You can assign a new value to an existing variable whenever your program needs it.

Example
score = 50
print(score)

score = 80
print(score)

Output:

50
80

The first print() displays 50. Later, the value of score is updated to 80. The second print() displays the new value.

Using the current value

You can also use a variable's existing value when assigning a new value to it. 

count = 5
count = count + 1

print(count)

Output:

6

Python first evaluates count + 1, which is 6, and then assigns that result back to count.

A shorter version is the addition assignment operator: 

count = 5
count += 1

print(count)

This also produces 6. The operators -=, *= and /= can be used in similar ways.

5. Assigning Multiple Variables

Python allows you to assign values to multiple variables in a single statement.

Assigning separate values

name, age, city = "Asha", 17, "Kochi"

print(name)
print(age)
print(city)

Output:

Asha
17
Kochi

Assigning the same value

You can also assign the same value to multiple variables: 

a = b = c = 10

print(a)
print(b)
print(c)

Output:

10
10
10

Multiple assignment can make simple code shorter. However, use separate statements when they make your program easier to understand.

6. Understanding Dynamic Typing

Python is a dynamically typed language. This means you do not have to declare a variable's data type in advance. Python determines the type from the value assigned to it.

Example
value = 100
print(value)

value = "Hello Python"
print(value)

Output:

100
Hello Python

First, value refers to an integer. Later, it refers to a string. Python allows this change.

Checking a variable's type

You can use the built-in type() function to find the type of value a variable currently refers to. 

age = 16
name = "Arun"
height = 1.75

print(type(age))
print(type(name))
print(type(height))

Output:

<class 'int'>
<class 'str'>
<class 'float'>

Dynamic typing does not mean every operation is allowed. For example, adding a number directly to a string can cause a TypeError. Understanding data types will help you avoid these problems.

7. Common Variable Mistakes

Beginners often make a few predictable mistakes when working with variables. Learning to recognise them makes debugging easier.

Mistake 1: Using a variable before assigning a value

print(age)
age = 16

This causes a NameError because age has not been assigned a value before it is used.

Mistake 2: Incorrect spelling

student_name = "Maya"
print(studentname)

student_name and studentname are different names. The second name has not been defined.

Mistake 3: Confusing assignment and comparison

age = 16       # Assigns a value
age == 16      # Checks whether values are equal

A single equals sign (=) assigns a value. Two equals signs (==) compare values.

Mistake 4: Using spaces in variable names

student age = 16  # Invalid
student_age = 16  # Valid

8. Practical Coding Exercises

Try these exercises in your Python editor or browser-based Python environment. Write the code yourself before checking the sample solutions.

Exercise 1: Personal information

Create variables for your name, age and favourite subject. Display all three values using print().

Sample solution
name = "Rahul"
age = 16
subject = "Physics"

print(name)
print(age)
print(subject)

Exercise 2: Simple calculation

Store two numbers in variables. Create a third variable that stores their sum, then display the result.

Sample solution
number1 = 25
number2 = 15

total = number1 + number2

print(total)

Exercise 3: Update a score

Create a variable named score with the value 10. Increase it by 5 and display the updated score.

Sample solution
score = 10
score += 5

print(score)

Exercise 4: Check data types

Create one integer, one string and one floating-point variable. Use type() to display their types.

10. Lesson Summary

In this lesson, you learned that:

  • Variables are names that refer to values.
  • The = operator assigns values to variables.
  • Variable names must follow Python's naming rules.
  • Python variable names are case-sensitive.
  • You can update a variable's value after creating it.
  • Python supports assigning values to multiple variables.
  • Python uses dynamic typing.
  • The type() function checks the type of a value.
