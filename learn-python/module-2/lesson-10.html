Basic Error Handling

Learn why Python errors happen and how to handle common exceptions using try, except, else, and finally.

1. What Are Errors in Python?

An error is a problem that prevents a program from working as expected. Errors can happen because of incorrect syntax, invalid operations, or unexpected data.

For example, trying to divide a number by zero causes an error in Python. 

number = 10
result = number / 0

print(result)

Python raises a ZeroDivisionError because division by zero is not allowed.

Why learn error handling? It helps programs respond to problems in a controlled way instead of stopping unexpectedly.

2. Types of Errors in Python

Python errors can be grouped into several categories. Understanding the differences helps you find and fix problems more easily.

Syntax Errors

A syntax error occurs when Python code does not follow the language's grammar rules. 

# Missing closing parenthesis
print("Hello"

Python detects this problem before the program can execute normally.

Runtime Errors (Exceptions)

Runtime errors happen while a program is running. Python calls these problems exceptions. 

number = int("hello")

This raises a ValueError because "hello" cannot be converted into an integer.

Logical Errors

A logical error happens when the program runs but produces an incorrect result because the logic is wrong. 

# Intended to calculate an average
total = 90
number_of_subjects = 3

average = total * number_of_subjects

print(average)
OUTPUT
270

The program runs without an exception, but the calculation is incorrect. It should divide the total by the number of subjects.

3. Common Python Exceptions

Python provides many built-in exception types. Here are some common ones you should recognize.

  • ZeroDivisionError: Dividing a number by zero.
  • ValueError: A value has an unsuitable format.
  • TypeError: An operation is used with an unsuitable type.
  • NameError: Using a name that has not been defined.
  • IndexError: Accessing a list or sequence position that does not exist.
  • KeyError: Looking up a missing dictionary key.
  • FileNotFoundError: Trying to open a file that cannot be found.
# ValueError
int("hello")

# TypeError
"Age: " + 16

# NameError
print(student_name)

These examples demonstrate different exceptions. Run them separately to observe the messages Python displays.

4. What Is Exception Handling?

Exception handling allows you to detect and respond to runtime problems. Python provides the try and except statements for this purpose.

The basic structure looks like this: 

try:
    # Code that might cause an exception
    risky_operation()

except SomeException:
    # Code that handles the exception
    print("Something went wrong.")

Python first runs the code inside try. If a matching exception occurs, it runs the corresponding except block.

Important: Exception handling does not automatically fix the underlying problem. It lets your program respond appropriately.

5. Using try and except

Consider a program that divides two numbers. The user might enter zero as the second number.

Without exception handling

number = 10
divisor = 0

result = number / divisor
print(result)

The program raises a ZeroDivisionError and does not reach the print statement.

With exception handling

try:
    number = 10
    divisor = 0

    result = number / divisor
    print(result)

except ZeroDivisionError:
    print("You cannot divide by zero.")
OUTPUT
You cannot divide by zero.

The exception is handled, so the program can continue after the try-except structure.

6. Handling Different Exceptions

You can use multiple except blocks to respond to different types of exceptions. 

try:
    number = int(input("Enter a number: "))
    result = 100 / number
    print("Result:", result)

except ValueError:
    print("Please enter a valid whole number.")

except ZeroDivisionError:
    print("The number cannot be zero.")

This program handles two possible problems:

  • If the input cannot be converted to an integer, it handles ValueError.
  • If the user enters zero, it handles ZeroDivisionError.

Good practice: Handle specific exceptions whenever possible. This makes it clearer which problems your program expects.

7. Using the else Block

The optional else block runs only when the code inside try completes without raising an exception. 

try:
    number = int(input("Enter a number: "))

except ValueError:
    print("Invalid input.")

else:
    print("You entered:", number)

If the user enters a valid integer, the else block runs. If conversion fails, the except block runs instead.

8. Using the finally Block

The optional finally block runs whether an exception occurs or not. It is commonly used for cleanup tasks. 

try:
    print("Starting program")
    number = 10 / 2

except ZeroDivisionError:
    print("Cannot divide by zero.")

finally:
    print("Program finished.")
OUTPUT
Starting program
Program finished.

Even if an exception occurs, the finally block normally runs as Python leaves the structure.

Understanding all four blocks

  • try contains code that may raise an exception.
  • except handles a matching exception.
  • else runs if no exception occurs in try.
  • finally runs when the structure is exited, whether an exception occurred or not.
try:
    print("Try block")

except ValueError:
    print("Except block")

else:
    print("Else block")

finally:
    print("Finally block")
OUTPUT
Try block
Else block
Finally block

9. Getting the Exception Message

You can store an exception in a variable using as. This allows you to display or inspect the exception message. 

try:
    number = int("hello")

except ValueError as error:
    print("Error:", error)
POSSIBLE OUTPUT
Error: invalid literal for int() with base 10: 'hello'

The exact wording of exception messages can vary between Python versions.

10. Raising Exceptions with raise

Python allows you to raise an exception yourself using the raise keyword.

This is useful when your program detects an invalid situation that should not be allowed. 

age = -5

if age < 0:
    raise ValueError("Age cannot be negative.")

This code raises a ValueError because a negative age is not valid for this example.

Remember: raise creates an exception. It does not handle one. You can use try-except elsewhere to catch an exception when appropriate.

11. Common Error Handling Mistakes

Mistake 1: Using an empty except block

# Avoid this
try:
    result = 10 / 0
except:
    pass

This hides the problem without explaining what happened. It can make debugging difficult.

Mistake 2: Catching every exception unnecessarily

A broad except Exception can be useful in carefully designed situations, but catching every possible problem may hide unexpected bugs.

Mistake 3: Putting unrelated code inside try

Keep the try block focused on the operations that may raise the exceptions you intend to handle.

Mistake 4: Forgetting to handle invalid input

When using input() with conversions such as int(), remember that invalid text can raise a ValueError.
