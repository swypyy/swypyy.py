Strings and String Operations

Learn how to store, access, modify, combine, and format text using Python strings.

1. What Are Strings?

A string is a sequence of characters used to represent text in Python. It can contain letters, numbers, symbols, spaces, and other characters.

For example, names, messages, addresses, and sentences are commonly stored as strings. 

name = "Ravi"
message = "Welcome to Python!"
city = "Kannur"

print(name)
print(message)
print(city)
OUTPUT
Ravi
Welcome to Python!
Kannur

In Python, strings belong to the built-in str data type. 

language = "Python"

print(type(language))
OUTPUT
<class 'str'>
Remember: Text must be placed inside quotation marks to be recognised as a string.

2. Creating Strings

Python allows you to create strings using single quotes, double quotes, or triple quotes.

Single Quotes

name = 'Anu'
print(name)
OUTPUT
Anu

Double Quotes

message = "Hello, Python!"
print(message)
OUTPUT
Hello, Python!

Triple Quotes

Triple quotes are useful for creating strings that span multiple lines. 

paragraph = """Python is easy to learn.
It is powerful and versatile.
It is used in many fields."""

print(paragraph)
OUTPUT
Python is easy to learn.
It is powerful and versatile.
It is used in many fields.
Tip: Single and double quotes work the same way for ordinary strings. Choose the style that makes your text easier to write.

3. Understanding String Indexing

Every character in a string has a position called an index. Python uses zero-based indexing, which means the first character is at index 0.

Example: Positive Indexing

Consider this string:

word = "PYTHON"

Its character positions are:

Character:  P   Y   T   H   O   N
Index:      0   1   2   3   4   5

You can access individual characters using their indexes.

word = "PYTHON"

print(word[0])
print(word[2])
print(word[5])
OUTPUT
P
T
N

Negative Indexing

Python also supports negative indexes. These start from the end of the string. 

word = "PYTHON"

print(word[-1])
print(word[-2])
print(word[-6])
OUTPUT
N
O
P
Remember: Indexing starts at 0 from the left and -1 from the right.

4. String Slicing

Slicing allows you to extract a portion of a string. It uses this syntax: 

string[start:end]

The starting index is included, but the ending index is excluded. 

word = "PYTHON"

print(word[0:3])
print(word[2:5])
print(word[:4])
print(word[2:])
OUTPUT
PYT
THO
PYTH
THON

Using a Step Value

Slicing also supports an optional step value: 

string[start:end:step]
word = "PYTHON"

print(word[::2])
print(word[::-1])
OUTPUT
 PTO
NOHTYP

The first example selects every second character. The second example reverses the string.

5. String Length

Python provides the built-in len() function to find the number of characters in a string. 

message = "Hello Python"

print(len(message))
OUTPUT
12

Spaces and punctuation marks are also counted as characters. 

text = "Hi!"

print(len(text))
OUTPUT
3

6. Combining Strings

You can combine strings using the addition operator +. This operation is called concatenation. 

first_name = "Ravi"
last_name = "Kumar"

full_name = first_name + " " + last_name

print(full_name)
OUTPUT
Ravi Kumar

Repeating Strings

The multiplication operator * repeats a string a specified number of times. 

word = "Python "

print(word * 3)
OUTPUT
Python Python Python

7. Useful String Methods

Python provides many built-in string methods that make working with text easier.

upper()

Converts all letters to uppercase.

text = "hello python"

print(text.upper())
OUTPUT
HELLO PYTHON

lower()

Converts all letters to lowercase.

text = "HELLO PYTHON"

print(text.lower())
OUTPUT
hello python

title()

Capitalises the first letter of each word.

text = "learn python programming"

print(text.title())
OUTPUT
Learn Python Programming

capitalize()

Capitalises the first character of the string.

text = "python is interesting"

print(text.capitalize())
OUTPUT
Python is interesting

strip()

Removes whitespace from the beginning and end of a string. 

text = "   Hello Python   "

print(text.strip())
OUTPUT
Hello Python

replace()

Replaces one part of a string with another.

text = "I like Java"

new_text = text.replace("Java", "Python")

print(new_text)
OUTPUT
I like Python

find()

Returns the index of the first occurrence of a substring. If it is not found, it returns -1. 

text = "Hello Python"

print(text.find("Python"))
print(text.find("Java"))
OUTPUT
6
-1

count()

Counts how many times a substring appears.

text = "banana"

print(text.count("a"))
OUTPUT
3

startswith() and endswith()

These methods check whether a string starts or ends with a particular sequence of characters. 

text = "python.org"

print(text.startswith("python"))
print(text.endswith(".org"))
OUTPUT
True
True
Important: String methods such as upper() and replace() return new strings. They do not change the original string.

8. String Formatting

String formatting allows you to insert variable values into text.

Using f-strings

F-strings are a clear and convenient way to include variables inside strings. Place f before the opening quotation mark and put variables inside curly brackets. 

name = "Anu"
age = 16

message = f"My name is {name} and I am {age} years old."

print(message)
OUTPUT
My name is Anu and I am 16 years old.

Using format()

The format() method is another way to insert values into a string. 

name = "Ravi"
age = 17

message = "My name is {} and I am {} years old.".format(name, age)

print(message)
OUTPUT
My name is Ravi and I am 17 years old.
Tip: F-strings are generally the easiest option for beginners when working with modern Python.

9. Strings Are Immutable

Strings in Python are immutable. This means that once a string is created, its individual characters cannot be changed directly.

The following code causes an error:

word = "Python"

word[0] = "J"

Instead, create a new string using the desired changes. 

word = "Python"

new_word = "J" + word[1:]

print(new_word)
OUTPUT
Jython

10. Common String Mistakes

Mistake 1: Forgetting quotation marks

name = Python

Python treats Python as a variable name, not as text. Use quotation marks: 

name = "Python"

Mistake 2: Using an invalid index

word = "Python"

print(word[10])

This causes an IndexError because index 10 does not exist in the string.

Mistake 3: Trying to modify a string directly

Remember that strings are immutable. Create a new string instead of changing an individual character.

Mistake 4: Confusing upper() with upper

String methods need parentheses when called. 

text = "hello"

print(text.upper())
