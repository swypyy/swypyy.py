What is Python?

Discover what Python is, understand programming languages, and explore how Python helps us communicate instructions to computers.

1. Introduction to Python

Python is a high-level, general-purpose programming language used to give instructions to computers.

It was created by Guido van Rossum and first released in 1991. Python is popular because its syntax is relatively simple, readable, and beginner-friendly.

Remember: Python is a programming language. It helps us write instructions that a computer can execute.

2. What is a Programming Language?

A programming language is a language humans use to write instructions that a computer can execute.

For example, we can write a program that tells a computer to:

  • Display a message.
  • Perform mathematical calculations.
  • Store and organize information.
  • Process data.
  • Build applications.

Python allows us to write these instructions in a way that is relatively easy for humans to read and understand.

3. Your First Python Example

Let's look at a simple Python program. It displays a message on the screen. 

print("Hello, World!")
Output
Hello, World!

This program uses Python's built-in print() function to display the text Hello, World!.

4. Understanding the Code

Let's understand the different parts of our program.

Code Meaning
print A built-in Python function that displays output.
() Parentheses that hold the function's argument.
"Hello, World!" The text that we want to display.
Text written inside quotation marks is called a string. You'll learn more about strings in Module 2.

5. Where Can Python Run?

Python is available on different operating systems, including:

  • Windows
  • macOS
  • Linux

You can also write and run Python programs using online coding environments through a web browser.

6. Why is Python Important?

Python is used in many areas of technology and science. Some important examples include:

  • Web development: Building websites and web applications.
  • Artificial intelligence: Developing systems that perform tasks requiring intelligent behaviour.
  • Machine learning: Training computers to identify patterns in data.
  • Data science: Analyzing and understanding information.
  • Automation: Using programs to perform repetitive tasks.
  • Scientific computing: Performing calculations and simulations.

We'll explore these applications in more detail as we continue learning Python.
