Module 1 · Lesson 8

Understanding How Your First Program Works

Discover what happens when Python runs your code. Learn about execution order, the interpreter, output, and common errors through simple examples.

1. Introduction

In the previous lesson, you wrote your first Python program using the print() function. You gave Python an instruction, and it displayed the expected message.

But what actually happens after you click Run? How does Python understand your instructions and produce the output?

Understanding this process helps you become a better programmer. Instead of only writing code, you begin to understand how your code behaves.

In this lesson: We will follow a small Python program from the code you write to the output you see.

2. How Python Reads Code

Python normally executes instructions in order, starting from the first executable line and moving towards the last.

Consider this program:

print("Good morning")
print("Welcome to Python")
print("Let's start learning")
Output
Good morning
Welcome to Python
Let's start learning

Python runs the first statement, then the second, and finally the third.

3. The Role of the Python Interpreter

A computer's processor does not directly understand Python source code. Python uses an interpreter implementation to process your program and help execute it.

When you run a Python file, the Python implementation processes the source code. In the standard CPython implementation, this involves compiling code into bytecode and executing it using the Python Virtual Machine.

What is an interpreter?

An interpreter is software that processes a programming language and helps execute its instructions.

What is bytecode?

Bytecode is an intermediate form of instructions produced by CPython before execution. It is not the same as the machine code executed directly by a processor.

Important: Python has different implementations. The details described here focus on CPython, the most widely used implementation.

4. Understanding Each Part of a Program

Let's look again at your first Python instruction: 

print("Hello, World!")

Function name: print

A function is a reusable block of code that performs a particular task. The built-in print() function displays information.

Parentheses

The parentheses contain the information passed to the function. This information is called an argument.

String

"Hello, World!" is a string value. It represents text that Python can display.

Function call

Writing a function name followed by parentheses to use it is called a function call. Here, print() is being called with one string argument.

5. How Output Is Produced

Let's follow a simple program through its execution process. 

print("Learning Python")
1. You write Python source code
↓
2. Python processes the code
↓
3. Instructions are executed
↓
4. The print() function displays text
↓
5. You see the output
Output
Learning Python

This is a simplified view of the process. The exact internal steps depend on the Python implementation and environment.

6. Understanding Execution Order

Python generally follows the order of instructions in your program. Let's see how changing the order changes the output.

Example 1: First order

print("One")
print("Two")
print("Three")
Output
One
Two
Three

Example 2: Different order

print("Three")
print("One")
print("Two")
Output
Three
One
Two

Python does not automatically rearrange your instructions. It follows the order in which the statements are executed.

Remember: Execution order is important. Later lessons will show how conditions, loops, and functions can change the normal flow of a program.

7. What Happens When There Is an Error?

Sometimes Python cannot execute a program because the code contains a mistake. These mistakes are called errors.

Syntax Errors

A syntax error occurs when code does not follow the rules of Python's grammar. 

print("Hello"

The closing parenthesis is missing. Python cannot correctly parse this statement.

Runtime Errors

A runtime error happens while a program is running. The code may be syntactically valid, but an operation cannot be completed. 

number = 10 / 0
print(number)

This attempts to divide a number by zero. Python raises a ZeroDivisionError.

Why should you understand errors?

  • Errors help identify problems in your code.
  • Error messages often point towards the problem.
  • Reading errors helps you learn how Python behaves.
  • Debugging helps you find and correct mistakes.

Tip: An error is information about something that needs attention. Read the message carefully instead of immediately changing random lines of code.
