Installing Python

Before writing and running Python programs on your computer, you need a Python installation. Let's set it up step by step.

1. Introduction

Python is a programming language, but your computer needs a Python implementation to run Python programs.

Installing Python gives your computer the tools needed to execute Python code. You can then write programs, test them and build projects.

Python can be installed on different operating systems, including:

  • Windows
  • macOS
  • Linux
Important: Use the official Python website or your operating system's trusted package manager to obtain Python.

2. Checking Whether Python Is Installed

Your computer may already have Python installed. Before installing it again, check whether it is available.

On Windows

  1. Open the Start menu.
  2. Search for Command Prompt or PowerShell.
  3. Open it and enter:
python --version

You can also try the Windows Python launcher: 

py --version

On macOS and Linux

Open the Terminal application and enter: 

python3 --version

Understanding the result

If Python is installed and available through your terminal, you may see a version number such as: 

Python 3.x.x

The exact version depends on your installation. If the command is not recognised or not found, Python may not be installed or may not be configured in your system's PATH.

3. Downloading Python

The official Python website provides downloads for supported operating systems.

1 Visit the official website

Open the official Python downloads page:

python.org/downloads

2 Choose your operating system

Select the appropriate download for Windows, macOS or another supported platform.

3 Download the installer

Follow the instructions on the official website to download the recommended installer for your system.

Download Python from the official website rather than unfamiliar third-party download sites.

4. Installing Python on Windows

Windows users can install Python using the official installer downloaded from python.org.

1 Open the installer

Find the downloaded Python installer and open it. The installation window will appear.

2 Enable PATH configuration

Look for the option named Add Python to PATH. Enable it if it is available.

PATH configuration allows you to run Python commands from Command Prompt or PowerShell without entering the full installation location.

3 Install Python

Select the standard installation option and follow the installer's instructions.

4 Wait for installation

Allow the installer to finish. Once it reports that installation is successful, close the installer.

5 Verify the installation

Open a new Command Prompt or PowerShell window and enter: 

python --version

If a Python version is displayed, the command is working.

If Python is already installed, you do not need to reinstall it just to follow this course.

5. Installing Python on macOS

macOS users can install Python using the official installer available on python.org.

1 Download Python

Visit the official Python downloads page and choose the macOS installer.

2 Open the installer

Open the downloaded installer package and follow the installation instructions.

3 Complete installation

Follow the setup steps until the installation finishes successfully.

4 Check Python

Open Terminal and enter: 

python3 --version
On macOS, use python3 to run Python 3 commands. The command named python may behave differently depending on your system configuration.

6. Installing Python on Linux

Many Linux distributions already include Python. You can check by opening Terminal and entering: 

python3 --version

If Python is missing, you can install it using your distribution's package manager.

Example: Ubuntu and Debian

sudo apt update
sudo apt install python3

Example: Fedora

sudo dnf install python3

These commands are examples for specific Linux distributions. Other distributions may use different package managers.

Avoid replacing or removing your system's existing Python installation. Some operating system tools may depend on it.

7. Verifying the Installation

After installing Python, check that it runs correctly. Open your terminal or command prompt.

Windows

python --version

You can also use:

py --version

macOS and Linux

python3 --version

You can also start the Python interactive interpreter by entering the appropriate command: 

python

On macOS and many Linux systems, use: 

python3

You may see a prompt that looks like this: 

>>>

This is the Python interactive prompt. You can enter Python instructions directly. 

>>> print("Python is working!")
Python is working!

To exit the interactive interpreter, enter exit().

8. Running Your First Python File

Now let's create a Python file and run it from your terminal.

1 Create a file

Open a text editor or code editor and create a new file named: 

hello.py

2 Write Python code

Add this code to the file:

print("My first Python file!")
print("Python is ready to use.")

3 Save the file

Save the file with the exact name hello.py.

4 Open the terminal

Open Command Prompt, PowerShell or Terminal. Navigate to the folder where you saved the file.

5 Run the program

On Windows, enter:

python hello.py

On macOS and Linux, enter:

python3 hello.py
Expected output
My first Python file!
Python is ready to use.

Congratulations! You have created and run a Python program from a file.

9. Common Installation Problems

Sometimes Python may not work immediately after installation. Here are some common problems and what they usually mean.

Problem 1: Python command not recognised

Your terminal cannot find the Python executable.

Possible solutions:

  • Check whether Python was installed successfully.
  • On Windows, check the PATH configuration.
  • Try the py command on Windows.
  • Open a new terminal after installation.

Problem 2: Wrong Python command

Some operating systems use different commands to start Python 3.

Try python3 on macOS or Linux, or py on Windows.

Problem 3: File not found

The terminal cannot find the Python file you are trying to run.

Possible solutions:

  • Check the spelling of the filename.
  • Make sure the file ends with .py.
  • Navigate to the folder containing the file.

Problem 4: Installation did not finish

The installer may have encountered an error or been interrupted.

Read the installer's error message and follow the official Python installation guidance for your operating system.

11. Lesson Summary

Installing Python prepares your computer to run Python programs.

  • Python can be installed on Windows, macOS and Linux.
  • The official Python website provides installation files.
  • Windows users can use the official installer.
  • macOS and Linux users can check Python using python3.
  • The --version command checks the installed version.
  • Python programs are commonly saved with the .py extension.
  • Terminal commands can run Python files.
Key takeaway: A successful installation means you are ready to start writing and running Python programs on your computer.
