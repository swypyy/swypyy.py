Setting Up a Code Editor

Learn how to choose a code editor, install Visual Studio Code, configure it for Python, and write and run your first program inside an editor.

1. Introduction to Code Editors

In the previous lesson, you learned how to install Python on your computer. Now you need a comfortable place to write and manage your Python programs.

A code editor is an application designed to help programmers write and work with code. It makes programming easier through useful features such as syntax highlighting, automatic suggestions, and error detection.

You can write Python code in a basic text editor, but a dedicated code editor provides tools that make larger programs easier to understand and maintain.

2. Text Editor vs Code Editor vs IDE

These three terms are related, but they do not mean exactly the same thing.

Type Purpose Example
Text Editor Creates and edits plain text files. Notepad
Code Editor Helps write and manage source code. VS Code
IDE Combines coding, running, debugging, and other development tools. PyCharm

Remember: A code editor focuses on writing code. An IDE usually provides a more complete development environment. Modern code editors can also gain many IDE-like features through extensions.

3. Popular Editors for Python

There are several tools you can use to write Python programs. Here are some popular choices:

Visual Studio Code (VS Code)

A free, lightweight code editor developed by Microsoft. It supports Python through an extension and offers features such as autocomplete, debugging, and an integrated terminal.

PyCharm

A Python-focused IDE developed by JetBrains. It provides advanced tools for writing, testing, and managing Python projects. It has a free Community Edition.

IDLE

IDLE is a simple development environment included with many standard Python installations. It is useful for beginners who want to start writing Python without installing another editor.

Jupyter Notebook

Jupyter Notebook lets you write and run code in separate cells. It is especially useful for experiments, data analysis, and learning through interactive examples.

4. Installing Visual Studio Code

In this lesson, we will use Visual Studio Code (VS Code) as our example editor.

  1. Open the official VS Code website.
  2. Choose the download option for your operating system.
  3. Download the installer.
  4. Open the installer and follow the installation instructions.
  5. Launch Visual Studio Code after installation.

Download VS Code only from its official website: https://code.visualstudio.com/

VS Code is available for Windows, macOS, and Linux. The installation steps may look slightly different depending on your operating system.

5. Setting Up Python in VS Code

Installing VS Code does not automatically give it every Python development feature. You should install the official Python extension.

Step 1: Open Extensions

Open VS Code and select the Extensions icon in the sidebar. You can also open the Extensions panel using Ctrl + Shift + X on Windows or Linux.

Step 2: Search for Python

Type Python in the Extensions search box. Find the Python extension published by Microsoft and select Install.

Step 3: Select Your Python Interpreter

Open the Command Palette using Ctrl + Shift + P on Windows or Linux. Search for: 

Python: Select Interpreter

Select the Python installation you want to use. The interpreter is the Python program that runs your code.

Important: If Python does not appear in the list, check that Python is installed correctly. You may need to restart VS Code after installation.

6. Creating Your First Python Project

A project is a folder containing the files related to a program. Keeping your work organized makes it easier to find and manage your code.

  1. Create a folder on your computer named PythonPractice.
  2. Open VS Code.
  3. Select File → Open Folder.
  4. Choose the PythonPractice folder.
  5. Create a new file named hello.py.

The .py extension tells your computer that the file contains Python source code. 

PythonPractice/
└── hello.py

7. Writing and Running Python Code

Open hello.py and type the following program: 

print("Hello from VS Code!")
print("I am learning Python.")

Save the file. You can now run it using the editor's Run Python File option, if available.

Another way is to open the integrated terminal in VS Code. Select Terminal → New Terminal and enter the appropriate command:

Windows

python hello.py

On some Windows installations, you can also use:

py hello.py

macOS and Linux

python3 hello.py
Expected Output
Hello from VS Code!
I am learning Python.

Congratulations! You have written and run a Python program using a code editor.

8. Understanding Common Editor Features

Syntax Highlighting

The editor displays different parts of your code in different colours. For example, Python keywords, strings, and numbers may each have different colours. This makes code easier to read.

Autocomplete

Autocomplete suggests possible words, functions, and code while you type. It can save time and help you discover available features.

Error Highlighting

The editor can underline or highlight possible problems in your code. These warnings help you notice mistakes, although not every warning means your program will fail.

Debugging

Debugging tools help you examine how a program runs. You can pause execution, inspect variable values, and follow the program step by step.

9. Common Setup Problems

Python is not recognized

Your terminal may not be able to find the Python installation. Check whether Python is installed and whether its command is available in your system PATH. On Windows, try py --version.

No Python interpreter selected

Open the Command Palette and choose Python: Select Interpreter. Then select your installed Python version.

Python extension is missing

Open the Extensions panel, search for the Python extension published by Microsoft, and install it.

Changes are not appearing

Save your file before running it. Check that you are running the correct file from the correct project folder.
