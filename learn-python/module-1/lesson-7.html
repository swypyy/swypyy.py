Your First Python Program

It is time to write your first Python program! Learn how to display messages, understand the print() function, perform simple calculations, and run your own code.

1. Introduction

You have learned what Python is, where it is used, how it works, and how to set up a code editor. Now it is time to put that knowledge into practice.

In this lesson, you will write a simple Python program and learn how to run it.

A program is a set of instructions that tells a computer what to do. Even a small instruction can be a complete program.

Your first goal: Make Python display the message "Hello, World!" on the screen.

2. Meet the print() Function

Python provides a built-in function called print(). It displays information in the output area or terminal.

For example: 

print("Hello!")
Output
Hello!

When Python executes this instruction, it displays the text Hello!.

3. Writing Your First Python Program

Let's create a Python file and write your first complete program.

Step 1: Create a file

Open your code editor and create a new file named hello.py.

Step 2: Write the code

Type the following instruction: 

print("Hello, World!")

Step 3: Save the file

Save your file with the name hello.py.

Step 4: Run the program

Open your terminal in the project folder and run the appropriate command. 

# Windows
python hello.py

# macOS or Linux
python3 hello.py
Expected Output
Hello, World!

That's your first Python program. The computer followed your instruction and displayed the message.

4. Understanding the Code

Let's understand each part of this instruction: 

print("Hello, World!")

print

print is the name of Python's built-in function used to display information.

Parentheses ( )

Parentheses contain the information that we pass to the function. In this example, the message is inside the parentheses.

Quotation Marks " "

Quotation marks tell Python that the content between them is text.

The Text or String

"Hello, World!" is a string. A string is a sequence of characters used to represent text.

Remember: The quotation marks are part of the Python code. They are not included in the displayed output.

5. Displaying Multiple Lines

You can use multiple print() statements to display several lines. 

print("Welcome to Python!")
print("This is my first program.")
print("I am learning programming.")
Output
Welcome to Python!
This is my first program.
I am learning programming.

Each print() statement normally moves the output to a new line.

Python executes these instructions in order, starting with the first line.

6. Printing Numbers and Calculations

The print() function can display numbers as well as text.

Printing a number

print(100)
print(25.5)
Output
100
25.5

Printing calculations

Python can also calculate mathematical expressions inside print(). 

print(10 + 5)
print(20 - 8)
print(6 * 4)
print(20 / 5)
Output
15
12
24
4.0

Python calculates each expression and displays its result.

Notice: Text is written inside quotation marks, while numbers and mathematical expressions can be written without them.

7. Common Beginner Mistakes

Small typing mistakes can prevent a program from running correctly. Here are some common examples.

Mistake 1: Missing quotation marks

# Incorrect
print(Hello)

# Correct
print("Hello")

Text should be placed inside quotation marks. Without them, Python may interpret the word as a variable name.

Mistake 2: Missing a closing parenthesis

# Incorrect
print("Hello"

# Correct
print("Hello")

Every opening parenthesis needs a matching closing parenthesis.

Mistake 3: Incorrect spelling

# Incorrect
pritn("Hello")

# Correct
print("Hello")

Python function names must be spelled correctly. pritn and print are different names.

Mistake 4: Using mismatched quotation marks

# Incorrect
print("Hello')

# Correct
print("Hello")

Use matching quotation marks around your text. You can use matching single quotes or double quotes.
