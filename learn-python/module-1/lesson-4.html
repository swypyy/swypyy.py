How Python Works

Have you ever wondered what happens after you press the Run button? Learn how Python code is processed and how the computer produces the result.

1. Introduction

When you write a Python program, you are giving instructions to a computer. But computers do not directly understand Python code.

A computer's processor works with machine instructions. Python uses software called an interpreter to help execute the program.

Let's understand this process step by step.

Key idea: Python code is written by programmers, and the Python implementation processes that code so the computer can execute it.

2. Writing Python Code

A Python program is usually written in a text editor or code editor. The instructions are saved in a file with the .py extension.

For example, a file named hello.py can contain this program: 

print("Hello, Python!")

This instruction tells Python to display the text Hello, Python! on the screen.

What is source code?

The human-readable instructions written by a programmer are called source code.

Python source code is generally easy for humans to read and understand compared with low-level machine instructions.

3. The Python Interpreter

An interpreter is a program that processes source code and helps execute its instructions.

When you run a Python program, the Python implementation reads the code, checks it and carries out the instructions according to Python's rules.

What does the interpreter do?

  • Reads the Python source code.
  • Checks whether the code follows Python's syntax rules.
  • Processes the instructions.
  • Executes the program and produces results.

Important distinction

In the common CPython implementation, Python source code is compiled into bytecode, which is then executed by the Python virtual machine.

So the simplified idea of an interpreter reading and executing code is useful for beginners, but the real process has additional steps.

A simplified representation of the execution process.

Step-by-step example

Consider this program: 

name = "Ravi"
print("Hello,", name)

When this program runs:

  1. Python processes the first instruction and stores the text "Ravi" in the variable name.
  2. Python processes the second instruction.
  3. The print() function displays the message using the stored value.
Output
Hello, Ravi

The output is the result produced when the program runs.

5. Python Is an Interpreted Language

Python is commonly described as an interpreted programming language. This means its code is executed through a software implementation rather than being directly translated into a standalone machine-code program in the usual beginner-level workflow.

What does interpreted mean?

In Python's common implementation, source code is compiled into an intermediate form called bytecode. The Python virtual machine then executes that bytecode.

This process makes it easier to run Python programs across different operating systems when a suitable Python implementation is installed.

Python's execution model is more detailed than simply reading one line at a time. The word "interpreted" is a useful general description, not a complete explanation of every implementation.

6. Python Implementations

Python is a programming language with several implementations. An implementation is software that follows Python's language rules and runs Python programs.

CPython

CPython is the standard and most widely used implementation of Python. It is written mainly in the C programming language.

Other implementations

  • PyPy: An alternative implementation that uses a Just-In-Time compiler to improve performance in many situations.
  • Jython: An implementation designed to run Python on the Java platform.
  • IronPython: An implementation designed for the .NET ecosystem.
Beginners generally start with CPython when installing Python from the official Python website.

7. Practical Example

Let's follow one complete program and understand what happens when it runs.

Program: Calculate the square of a number

number = 6
square = number * number

print("Number:", number)
print("Square:", square)
Output
Number: 6
Square: 36

Understanding the execution

  • Python processes the instruction that assigns 6 to the variable number.
  • It calculates number * number and stores the result in square.
  • The first print statement displays the number.
  • The second print statement displays the square.

You can run this example using the Python interpreter installed on your computer or a browser-based Python environment.

9. Lesson Summary

Python programs contain instructions written by programmers. A Python implementation processes these instructions and executes the program.

  • Python source code is commonly saved in .py files.
  • The Python interpreter processes the source code.
  • CPython compiles source code into bytecode.
  • The Python virtual machine executes bytecode.
  • Program execution produces results or output.
  • CPython is the most widely used Python implementation.
Key takeaway: Writing code is only one part of programming. Understanding how a program runs helps you become a better programmer.
